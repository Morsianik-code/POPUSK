# Капри — экранный питомец

Android-приложение: маленький неоновый кибер-дух живёт поверх всех приложений.
Ходит по низу экрана, лезет по краям, висит на верхнем крае, запрыгивает на сообщения
и иконки, сидит и болтает ножками, иногда засыпает. Его можно тапнуть, перетащить и кинуть.

Kotlin, обычные View, Android 8.0+ (minSdk 26, targetSdk 34). Сторонних библиотек нет.

## Как скачать APK

Собирать ничего не нужно — APK собирает GitHub Actions при каждом пуше.

1. Открой репозиторий на GitHub в браузере (не в приложении GitHub — там артефакты не скачать)
   и войди в аккаунт: без входа кнопки скачивания нет.
2. Вкладка **Actions** → слева **Build APK** → верхний запуск с зелёной галочкой.
3. Пролистай вниз до блока **Artifacts** и нажми **kapri-debug-apk** — скачается zip-архив.
4. Распакуй архив (в «Файлах» телефона: нажать на архив → «Извлечь»). Внутри лежит `app-debug.apk`.

Артефакты хранятся 90 дней. Если запуск старый и артефакт пропал: Actions → Build APK →
**Run workflow** — соберётся свежий.

## Как установить

1. Нажми на `app-debug.apk`.
2. Android спросит разрешение на установку из этого источника (браузер или «Файлы») — разреши и вернись назад.
3. Нажми «Установить». Если Play Защита предупредит о неизвестном разработчике — «Всё равно установить».

Обновления ставятся поверх старой версии: все сборки подписаны одним ключом из репозитория.

## Как выдать разрешения

Открой «Капри». В блоке «Разрешения» у каждого пункта есть объяснение и кнопка «Выдать».

| Разрешение | Зачем | Обязательно |
| --- | --- | --- |
| **Поверх других приложений** | Питомцу нужно окошко поверх экрана. В открывшемся списке найди «Капри» и включи переключатель. | Да |
| **Специальные возможности** | Чтобы видеть, где на экране сообщения, иконки и кнопки, и садиться на них. | Нет |
| **Уведомления** | Тихое уведомление с кнопкой «Выключить», пока питомец включён. | Нет |
| **Не усыплять приложение** | Чтобы система не закрыла питомца ради экономии заряда. | Желательно |

### Если «Специальные возможности» не включаются

На Android 13 и новее для приложений, установленных из файла, эта настройка сначала заблокирована
(«Настройка ограничена» / «Restricted setting»). Чтобы снять блокировку:

1. Попробуй включить «Капри» в «Специальных возможностях» один раз — появится сообщение о блокировке.
2. Открой **Настройки → Приложения → Капри**.
3. Нажми **⋮** справа вверху → **«Разрешить ограниченные настройки»**.
4. Вернись в «Специальные возможности» → «Скачанные приложения» → «Капри» и включи.

На Xiaomi, Huawei, Oppo и подобных прошивках дополнительно стоит разрешить приложению
автозапуск и работу в фоне в настройках батареи, иначе система может выгружать питомца.

После этого включи переключатель **«Питомец на экране»**.

## Настройки

- **Размер, скорость, непрозрачность** — ползунки, применяются сразу.
- **Садиться на элементы интерфейса** — питомец использует верхние края сообщений, иконок
  и других крупных элементов как платформы. При прокрутке платформы обновляются;
  если платформа исчезла — питомец падает. Можно выключить.
- **Не мешать в полноэкранном видео** — в полноэкранном режиме питомец становится меньше и прозрачнее.
- **Свой скин** — выбери картинки-кадры из галереи для каждой анимации (идёт, сидит, лезет,
  падает, его тащат, спит) и задай скорость в кадрах в секунду. Кадры копируются внутрь
  приложения. Рисуй персонажа лицом вправо, «лезет» — у левой стены. Если для анимации
  кадров нет, берутся кадры «идёт».

Выключить питомца: переключателем в приложении или кнопкой «Выключить» в уведомлении.
После перезагрузки телефона питомец сам не запускается.

## Приватность

Сервис специальных возможностей читает только координаты видимых элементов экрана.
Тексты и содержимое не сохраняются и никуда не отправляются: у приложения нет разрешения
на интернет. Пока питомец выключен или экран погашен, экран не читается вообще.

## Что стоит знать

- В Telegram платформой служит строка сообщения целиком, а не сам пузырь: Telegram не сообщает
  системе точные границы пузыря, только границы строки. Питомец садится на уровне верхнего
  края сообщения, но иногда сбоку от пузыря.
- Приложения, которые рисуют всё сами (игры, часть видеоплееров), элементов не отдают —
  там питомец ходит только по полу и краям экрана.

## Для разработки

```
./gradlew assembleDebug
```

APK появится в `app/build/outputs/apk/debug/`. Нужны JDK 17 и Android SDK 34.

| Файл | Что делает |
| --- | --- |
| `PetService.kt` | Foreground-сервис: окно поверх экрана, кадры через Choreographer, касания |
| `PetEngine.kt` | Физика и поведение (машина состояний) |
| `SpiritRenderer.kt` | Встроенный персонаж, нарисованный на Canvas |
| `PlatformService.kt` | Сервис специальных возможностей: координаты элементов |
| `SkinStore.kt`, `SkinActivity.kt` | Свой скин |
| `MainActivity.kt` | Главный экран и разрешения |
