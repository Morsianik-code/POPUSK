# Popusk Widgets

Android-приложение со своими виджетами для рабочего экрана в стиле OriginOS:
белые карточки с крупным скруглением, большие цифры, цветные кольца.

## Виджеты

| Виджет | Размер | Что показывает |
|---|---|---|
| **Часы и погода** | 4×1 | время, дата, температура, дуга солнца с ближайшим восходом/закатом |
| **Активность** | 4×2 | шаги, калории, минуты тренировки, три кольца прогресса, дистанция |
| **Погода** | 2×2 | город, температура, состояние, мин/макс, световой день |

У всех три стиля: светлый, тёмный и «стекло» (полупрозрачный).

- Погода — [open-meteo.com](https://open-meteo.com) (бесплатно, без ключа). Город ищется по названию или берётся из геолокации.
- Шаги — аппаратный датчик `TYPE_STEP_COUNTER`. Калории и дистанция — оценка по шагам, «тренировка» — минуты быстрой ходьбы.
- Тап по часам открывает будильники, по активности/погоде — обновляет данные.

## Как получить APK

Каждый пуш собирается в GitHub Actions: вкладка **Actions** → последний запуск **Build APK** →
артефакт `popusk-widgets-apk`. Внутри `app-debug.apk` — его и ставить на телефон.

APK подписан общим ключом из `keystore/`, поэтому новые версии ставятся поверх старых.

## Сборка локально

Android Studio (или JDK 17 + Android SDK 35):

```
./gradlew assembleDebug
```

## Структура

```
app/src/main/java/dev/popusk/widgets/
  MainActivity.kt     экран настроек с живыми превью и кнопками «добавить на экран»
  Widgets.kt          AppWidgetProvider'ы и обновление всех виджетов
  WidgetViews.kt      RemoteViews каждого виджета
  Renderers.kt        отрисовка колец и дуги солнца
  Weather.kt          погода, восход/закат, поиск города
  StepTracker.kt      подсчёт шагов за день
  WidgetTheme.kt      цвета стилей
app/src/main/res/layout/widget_*.xml   разметка виджетов
```
