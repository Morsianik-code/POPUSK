# Маленький тест

Одностраничный сайт-признание: Liquid Glass, живой 3D-фон на Three.js,
вопросы → результат → письмо → финал. Всё в одном файле `index.html`,
без сборки и установки.

## Как пользоваться

1. Открой `index.html` и найди блок `window.CONFIG` в начале первого `<script>`.
2. Поменяй `name` (её имя), тексты вопросов, письмо и подпись.
3. `replyUrl` — ссылка «Написать мне» в финале (например `https://t.me/username`).
   Если оставить пустым, вместо неё будет кнопка «Ещё раз».
4. Залей файл на любой статический хостинг (GitHub Pages, Vercel, Netlify)
   или просто отправь ссылку на страницу.

## Что внутри

- Шрифты: Cormorant Garamond (заголовки), Marck Script (рукописные акценты),
  Manrope (текст), Unbounded (цифры). Все с кириллицей, грузятся с Google Fonts.
- 3D: Three.js с CDN (jsDelivr). Мягкие полупрозрачные «пузыри» в цветах фона: капля с «жидкой» поверхностью,
  сердце и несколько сфер; живой градиентный фон,
  искры и взрыв частиц в финале.
- Если WebGL или сеть недоступны, включается CSS-фон, и тест работает всё равно.

# 🎃 Хэллоуин-версия — `halloween/`

Тот же сайт (вопросы → результат → письмо → финал), но с другими текстами
и в максимально хэллоуинском стиле. Открывается по адресу `…/halloween/`.

## Как пользоваться

Все тексты — в `halloween/index.html`, блок `window.CONFIG`:

- `name`, `replyUrl` — как в основной версии;
- `questions` — у каждого ответа есть `is`: какая нечисть за ним стоит
  (`pumpkin`, `ghost`, `vampire`, `witch`). Результат — та, за кого больше ответов;
- `onEnter` / `onAnswer` — какая пугалка срабатывает на вопросе:
  `bats`, `peek`, `spider`, `cat`, `lightning`, `dark`, `boo`;
- `creatures` — имена и описания для результата;
- `sound: false` — звук по умолчанию выключен, `scares: false` — без скримеров.

## Что внутри

- **3D-фон** (Three.js): ночное небо с туманом и мерцающими звёздами, Луна
  с настоящей текстурой, тыквы-фонари с горящими вырезанными лицами,
  милые привидения (моргают и машут ручками), стая летучих мышей у Луны.
- **Пугалки**: стая летучих мышей, привидение выглядывает из-за края экрана,
  паук спускается на паутинке (его можно спугнуть), кот выглядывает снизу,
  молнии с громом, вопрос «кто выключил свет?» — свети мышкой или пальцем,
  и главный скример «БУ!» (мило, без крови).
- **Результат**: одометр «случайно» докручивается до 666, ломается —
  и чертёнок признаётся, что это не та цифра.
- **Письмо** — «официальное проклятие» на пергаменте с сургучной печатью.
- **Финал**: огромная тыква на фоне полной Луны, дождь из конфет.
- **Звук** целиком синтезируется Web Audio (никаких файлов): гул, ветер,
  музыкальная шкатулка, гром, «бу!», писк мышей, мяу. Кнопка справа вверху.

## Откуда картинки

- 3D-эмодзи — [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) (MIT, лицензия в `halloween/assets/LICENSE-fluentui-emoji.txt`).
- Текстура Луны — из примеров [three.js](https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets) (MIT).
- Шрифты — Google Fonts: Rubik Wet Paint, Caveat, Kurale, Nunito, Unbounded.
